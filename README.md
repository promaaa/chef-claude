# Chef Claude

AI-powered recipe generator with OpenAI, Mistral, and Gemini integration.

## Features

- Multiple AI providers (OpenAI, Mistral, Gemini)
- Demo mode (no API key required)
- Dark/Light theme
- Responsive design
- Fast generation

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
./deploy.sh
```

## Tech Stack

- React 19
- Vite
- CSS Variables
